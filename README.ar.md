# 🏦 نظام إدارة البنك (C++)

مشروع **Bank System** تم تطويره باستخدام **C++** ضمن مشاريع **Programming Advices – Course 7**.

يعمل البرنامج من خلال واجهة سطر الأوامر (Console)، ويستخدم ملفًا نصيًا لحفظ بيانات العملاء وإدارتها.

---

## ✨ المميزات

* 📋 عرض جميع العملاء
* ➕ إضافة عميل جديد
* ✏️ تعديل بيانات العميل
* ❌ حذف عميل
* 🔍 البحث عن عميل بواسطة رقم الحساب
* 💾 حفظ بيانات العملاء داخل ملف نصي
* 📂 تحميل البيانات عند تشغيل البرنامج
* 🖥️ واجهة Console بسيطة وسهلة الاستخدام

---
