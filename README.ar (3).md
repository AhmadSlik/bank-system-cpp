# نظام البنك — C++ Console App 🏦

برنامج على الطرفية (console) لإدارة سجلات العملاء بعمليات CRUD كاملة (إضافة، عرض، تعديل، حذف)، مبني بلغة ++C، وكل سجل بينحفظ ويتحمّل من ملف نصي.

> المشروع الأول من كورس **Algorithms & Problem Solving Level 3** (الكورس السابع من خارطة الطريق للدكتور محمد أبو هدهود).

## المميزات

- إضافة عميل جديد (رقم حساب، رمز PIN، اسم، هاتف، رصيد) — مع منع تكرار رقم الحساب
- عرض كل العملاء بجدول منظم ومحاذى
- البحث عن عميل واحد برقم الحساب
- تعديل بيانات عميل موجود، مع تأكيد قبل الحفظ
- حذف عميل، مع تأكيد قبل الحذف
- كل البيانات محفوظة بملف `ClientRecord.txt` — ما بتضيع بين مرة وتانية
- القائمة الرئيسية بترجع لحالها بعد كل عملية، لحد ما تختار الخروج

## طريقة التشغيل

```bash
g++ main.cpp -o bank_system
./bank_system
```

> البرنامج يستخدم أمر خاص بنظام Linux (`system("clear")`) لمسح الشاشة، فأفضل تشغيل له على Linux أو macOS.

## المفاهيم المطبّقة

- التعامل مع الملفات (`fstream`) لعمل CRUD كامل بيحفظ ويرجع
- `vector` لتحميل كل السجلات بالذاكرة
- صيغة سطر مخصصة — الحقول متفصلة بفاصل `#//#`، وبتنفك من جديد وقت القراءة
- الحذف والتعديل الاثنين بيشتغلوا بإعادة كتابة الملف كامل: الملف النصي ما فيه طريقة تحذف أو تعدّل سطر لحاله، فالحل الآمن إنك تكتب كل سجل (المحفوظ أو المعدَّل) بنسخة جديدة
- `struct` لتجميع بيانات العميل، و`enum` لخيارات القائمة
- تمرير المتغيرات بالمرجع (`&`) لتحديث القائمة بالذاكرة بدون نسخها
- Recursion — البرنامج بيرجع عالقائمة الرئيسية باستدعاء نفسه من جديد، مش بحلقة تكرار
