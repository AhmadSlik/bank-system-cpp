# 🏦 Bank System (C++)

A simple **Bank System** built with **C++** as part of the Programming Advices Course 7.

The application is a console-based client management system that stores data in a text file and allows basic banking client operations through an interactive menu.

---

## ✨ Features

* 📋 Show all clients
* ➕ Add new clients
* ✏️ Update client information
* ❌ Delete clients
* 🔍 Find clients by account number
* 💾 Store client records in a text file
* 📂 Load client data from file on startup
* 🖥️ Simple console menu interface

---

## 🛠️ Technologies

* C++
* File Handling (`fstream`)
* STL Vector
* String Processing
* Console Application
